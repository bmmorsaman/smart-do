# ผู้ใช้บน MongoDB

สร้าง Admin แรกด้วย `npm run db:init` ตาม [คู่มือติดตั้ง](deployment.md) แล้วล็อกอินด้วยอีเมลที่ตั้งไว้ เมนูจัดการผู้ใช้แยกจากตั้งค่าทั่วไปและไม่แสดงในโหมดทดลอง

สร้างบัญชีด้วยอีเมล ชื่อ รหัสผ่านอย่างน้อย 8 ตัวอักษร และสิทธิ์:

- admin: จัดการบัญชี ตั้งค่า ทะเบียนและรับ/จ่าย
- officer: ตั้งค่า ทะเบียน รับ/จ่ายและอ่านรายงาน
- viewer: อ่านข้อมูลและรายงาน

API ตรวจสิทธิ์ทุกคำขอ เก็บรหัสผ่านแบบ salted scrypt ไม่ส่ง hash หรือ salt ในรายการผู้ใช้ หน้านี้รองรับเพิ่มบัญชีและดูรายการ ยังไม่รองรับเปลี่ยนรหัสผ่านหรือลบบัญชี
