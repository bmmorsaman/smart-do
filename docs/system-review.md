# ทบทวนระบบวัสดุ 7 ตุลาคม 2569

Flow ปัจจุบัน: ตั้งค่า → เพิ่ม/นำเข้าทะเบียน → รับวัสดุ → จ่ายวัสดุ → Stock Card/ประวัติ → รายงาน

## สิ่งที่ปรับให้ตรงกับการใช้งาน

- หน้าแรกและภาพรวมกล่าวถึงวัสดุ แสดงข้อมูลแยกตามหมวดจริง
- แยกรับกับจ่าย ไม่มีตัวเลือกประเภทซ้ำ ผู้ควบคุมวัสดุและผู้รับเลือกจากตั้งค่า
- วันที่ทำรายการแยกจากเวลาบันทึกจริง รองรับย้อนหลังโดยตรวจยอดตามวัน
- ทะเบียนมีหมวดและหน่วยนับบังคับ ราคาต้องเป็นจำนวนที่ถูกต้อง ยอดใหม่ศูนย์ แก้ยอดผ่านรับ/จ่ายเท่านั้น
- นำเข้า CSV ตรวจรหัสซ้ำ หมวด และหน่วยที่เปิดใช้งาน มีตัวอย่าง 3 รายการ
- Stock Card ดูประวัติอย่างเดียว ไม่มีแบบฟอร์มรับ–จ่ายรุ่นเก่า และมีประวัติทะเบียนรายวัสดุ
- ประวัติโดยรวมค้นหาวัสดุได้ แสดงชื่อรายการและข้อมูลก่อน/หลังเป็นตาราง
- รายงาน 6 แบบตรงกับข้อมูลที่ระบบบันทึก ไม่แสดงรายงานตรวจนับที่ไม่มีหน้ากรอกแล้ว
- ตั้งค่าเพิ่ม แก้ ปิดใช้งาน และลบได้ ไม่เปลี่ยนค่าที่บันทึกในประวัติเดิม
- โหลดทะเบียนและตั้งค่าจาก Supabase แบบแบ่งหน้า ไม่ตัดรายการที่ 1,000
- หน่วยนับของวัสดุที่เคยรับ–จ่ายเปลี่ยนไม่ได้ เพื่อป้องกันประวัติและรายงานเปลี่ยนความหมาย

## ตัวอย่างครอบคลุม

| รายการ | กรณี |
| --- | --- |
| MAT-001 | ยกมาจากเดือนก่อน รับและจ่ายเดือนนี้ |
| MAT-002 | ต่ำกว่าจุดสั่งซื้อ |
| MAT-003 | รับแล้วจ่ายจนหมด |
| MAT-004 | ถึงจุดสั่งซื้อพอดี |
| MAT-005–007 | ยอดปกติและผู้ควบคุมหลายคน |
| MAT-008 | รับบริจาค ราคาศูนย์ |
| MAT-009 | ประวัติรับเก่าไม่ทราบราคา |
| MAT-010 | ทะเบียนใหม่ ไม่มีการรับเข้า |
| MAT-011 | จำนวนทศนิยม |
| MAT-012–016 | หมวดและหน่วยเพิ่มเติมให้ครบรายการตั้งค่า |

มีวัสดุ 16 รายการ 6 หมวด 12 หน่วย ใช้ผู้ควบคุมทั้ง 4 คนและผู้รับทั้ง 6 คน ประวัติรับ–จ่ายรวมเป็นยอดคงเหลือของแต่ละวัสดุ ตัวอย่างตั้งค่าและการแก้ไข/ลบ/รีเซ็ตตรวจผ่านเบราว์เซอร์

ข้อมูลจริงไม่ได้ถูกรีเซ็ต และยังไม่ได้อัปเกรด Supabase จริง โครงการเดิมต้องรัน migration ถึง 010 ก่อนใช้โค้ดปัจจุบัน ประวัติการแก้ไขแสดง 200 รายการล่าสุด ส่วนประวัติรับ–จ่ายโหลดทั้งหมด
