# หน้ากระดาษแบบบัญชีวัสดุ

อ้างอิงระยะขอบจาก `เบิกวัสดุ.docx` โดยปรับขนาดกระดาษเป็น A4 ตามคำขอผู้ใช้ (หน่วย Word: 1 นิ้ว = 1440 twips)

| รายการ | ค่าใน Word | ค่าที่ใช้พิมพ์ |
|---|---:|---|
| ขนาด | ต้นฉบับ Letter แนวนอน | A4 แนวนอน 297 × 210 มม. |
| ขอบบน | 964 twips | 48.2 pt ≈ 17.004 มม. |
| ขอบล่าง | 680 twips | 34 pt ≈ 11.994 มม. |
| ขอบซ้าย / ขวา | 1440 twips | 72 pt = 25.4 มม. |
| หัว / ท้ายกระดาษ | 720 twips | 12.7 มม. จากขอบกระดาษ (ต้นฉบับไม่มีเนื้อหาหัว/ท้ายกระดาษ) |
| เผื่อเย็บ | 0 | 0 |

พื้นที่เนื้อหา 246.2 × 181.002 มม. ระบบกำหนดกระดาษ A4 แนวนอนและระยะขอบด้วยหน่วย pt พร้อมใช้ TH Sarabun New ขนาดข้อมูลวัสดุและข้อความอื่น 10 pt หัวเรื่อง 18 pt และตาราง 10 pt

ในหน้าต่างพิมพ์เลือก A4, แนวนอน, มาตราส่วน 100% และปิดหัวกระดาษ/ท้ายกระดาษของเบราว์เซอร์ เพื่อไม่ให้ URL ชื่อเว็บ และวันเวลาติดเอกสาร อย่าเปลี่ยนระยะขอบเป็นค่าอื่น

ค่าหน้ากระดาษนี้ใช้เฉพาะแบบบัญชีวัสดุจาก Word แบบเดิมและรายงานอื่นยังใช้ A4
