# ระบบคำนวณ จัดเก็บข้อมูล และรายงาน

ตามขอบเขตที่ผู้ใช้กำหนด ระบบใช้บันทึกทะเบียน คำนวณ และจัดทำรายงาน นำรายการตรวจความพร้อม การเสนอ/อนุมัติ และการล็อกเนื้อหาตามสถานะออกแล้ว ทั้งหน้าจอ โหมดทดลอง และ SQL

- ผู้บันทึก admin/officer เพิ่มและแก้ไขข้อมูลได้ โดยไม่ต้องกรอกเอกสารสำหรับการเสนออนุมัติให้ครบ
- ฟอร์มยังตรวจรหัส ชื่อ ปีงบประมาณ จำนวนเงิน และข้อมูลที่จำเป็นต่อการคำนวณค่าเสื่อม
- Stock Card แสดงจำนวนและมูลค่ารับ จ่าย คงเหลือ เก็บราคาขณะทำรายการ พร้อม CSV/PDF
- คลังวัสดุยังป้องกันจ่ายเกินยอด และเปลี่ยนยอดผ่านรายการรับจ่ายพร้อมหลักฐาน
- เอกสารต้นทางใช้ประกอบข้อมูลและรายงาน ไม่บังคับผ่านสถานะอนุมัติ
- เก็บประวัติก่อน/หลังแก้ไข และคงสิทธิ์อ่าน/บันทึกตามบัญชี
- ค่าสถานะเดิมยังอยู่ในข้อมูลเพื่อรักษาประวัติ แต่ไม่ได้ใช้ล็อกการบันทึกหรือแสดงเป็นขั้นตอนอนุมัติ

Supabase ใหม่ใช้ `supabase/schema.sql` โครงการเดิมใช้ migration ตามลำดับ 001, 002 และ `003_records_reports_only.sql` โครงการที่อัปเกรด 001/002 แล้วใช้เฉพาะ 003 เพื่อถอนขั้นตอนอนุมัติ ไม่ลบข้อมูลเดิม

ผลทดสอบ: 16 กรณีใน Node/PostgreSQL จำลอง และ 31 จุดใน Chrome รวมการแก้ข้อมูลเดิมที่มีสถานะอนุมัติ โดยระบบไม่ล็อกเนื้อหา การคำนวณ Stock Card ประวัติ และรายงาน ยังไม่ได้เชื่อม Supabase จริง
