# SMART วัสดุ — รพ.สต.บ้านโดนเอาว์

ระบบทะเบียน รับวัสดุ จ่ายวัสดุ Stock Card ประวัติ และรายงาน รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

ใช้ **MongoDB Atlas** เก็บข้อมูล, **GitHub** เก็บโค้ด และ **Vercel** รันหน้าเว็บพร้อม API ไม่เชื่อม Google Sheets หรือ Supabase ในโปรแกรมปัจจุบัน

## รันในเครื่อง

ใช้ Node.js 22.12 ขึ้นไป:

```sh
npm ci
npm run dev
```

โหมดทดลองใช้ข้อมูลในเบราว์เซอร์ได้ทันที ข้อมูลจริงต้องตั้ง MongoDB ก่อน Vite มี API ฝั่งเซิร์ฟเวอร์ในเครื่อง ไม่ต้องใช้ Vercel CLI เพื่อรันในเครื่อง

## ตั้งฐานข้อมูลและ Admin แรก

คัดลอก .env.example เป็น .env.local แล้วใส่ MONGODB_URI, MONGODB_DB และ INITIAL_ADMIN_EMAIL/PASSWORD/NAME รหัสผ่านอย่างน้อย 8 ตัวอักษร จากนั้น:

```sh
npm run db:init
npm run dev
```

คำสั่งสร้าง indexes และ Admin แรก ไม่ล้างข้อมูลเดิม ลบ INITIAL_ADMIN_PASSWORD หลังสำเร็จ เก็บ MONGODB_URI ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามใส่ VITE_ นำหน้า

ดู [ติดตั้ง MongoDB, GitHub และ Vercel](docs/deployment.md) และ [จัดการผู้ใช้](docs/user-management.md)

## การใช้งาน

1. ตั้งค่าผู้ควบคุมวัสดุ ผู้รับ หมวด หน่วยนับ สถานที่เก็บ รับจาก โลโก้และข้อมูลหน่วยงาน
2. เพิ่มทะเบียนหรือ CSV ยอดเริ่มต้นศูนย์ แล้วรับวัสดุเพื่อเพิ่มยอด
3. รับ/จ่ายแยกหน้า ระบบคำนวณมูลค่า ตรวจยอดและวันที่ย้อนหลัง
4. ดู Stock Card รายงาน CSV และพิมพ์/PDF แบบเดิมหรือบัญชีวัสดุ
5. Admin เพิ่มบัญชีจากเมนูแยก; officer บันทึก; viewer อ่านอย่างเดียว

บัญชีวัสดุใช้ TH Sarabun New A4 แนวนอน หัวเรื่อง 18pt ข้อมูลและตาราง 10pt ปิด Headers and footers ในหน้าต่างพิมพ์เพื่อเอาข้อความที่เบราว์เซอร์เติมออก

## ตรวจสอบ

```sh
npm test
npm run build
```

API อยู่ใน api/data.js เซิร์ฟเวอร์อยู่ใน server/ รับ/จ่ายใช้ MongoDB transaction เพื่อบันทึกยอด ประวัติ และ audit พร้อมกัน ต้องใช้ Atlas หรือ replica set ข้อมูลเดิมไม่ถูกย้ายอัตโนมัติ ไฟล์ supabase/ และชุดทดสอบ SQL เป็นข้อมูลระบบเก่า
